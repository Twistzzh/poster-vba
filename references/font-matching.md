# 中文字体精准匹配指南

展板复刻的字体目标：**家族对、层级对、大小对**。中文用引擎的 NameFarEast 槽
（`FONT_NAME_CN`），西文用 `FONT_NAME`——两个槽都要写，缺省时中文会掉到宋体。

## 1. 从原图识别字体家族（看笔画特征）

| 原图特征 | 类别 | Windows 常见候选（按优先级） |
|---|---|---|
| 横竖等粗、无衬线、端点方正 | 黑体/无衬线 | 微软雅黑 > 思源黑体 > 黑体(SimHei) |
| 横细竖粗、有衬线、末端三角 | 宋体/衬线 | 华文中宋 > 宋体 > 思源宋体 |
| 笔画带毛笔起收锋、婀娜 | 楷体 | 楷体 > 华文楷体 > 霞鹜文楷 |
| 连笔手写、倾斜飘逸 | 行楷/手写 | 华文行楷 > 方正舒体 |
| 端点圆头、憨厚可爱 | 圆体 | 幼圆 >（下载站酷快乐体/思源圆体） |
| 笔画极粗、方正如牌匾 | 综艺/粗黑 | 华文琥珀 >（下载方正综艺） |
| 弯钩夸张、装饰性强 | 美术字 | 华文琥珀 / 华文彩云（少用） |
| 数字/英文与中文异族 | 混排 | 西文常配 Arial / Calibri / Impact |

判断技巧：放大截图看**单字**——先看"横"的粗细变化（等粗=黑体类），
再看端点（圆头=圆体，三角=宋体），再看弯钩（楷/行楷的钩有书法锋）。

## 2. 验证已安装 + 找回退

```bash
python scripts/font_check.py 微软雅黑 思源黑体 华文行楷 楷体 幼圆
python scripts/font_check.py --list 圆      # 按关键字列出已装字体
```

- 输出 `[可用]` → 直接把家族名写进常量（用输出的英文家族名更稳，
  如 `Microsoft YaHei`；中文别名亦可，PowerPoint 都认）。
- 输出 `[未安装]` → 用它建议的"已安装相近字体"（同类别优先），
  或按提示下载免费可商用字体后重跑验证。
- **不要写未验证的字体名**：PowerPoint 找不到字体会静默替换，
  渲染结果与原图差距大且难察觉。

## 3. 字号测算（禁止目测一律 12pt）

画布 px → 磅的换算：`pt = 字形像素高 × PX_TO_IN × 72 ÷ 字面率`。
汉字字面率≈0.92，西文大写高≈0.70：

```
汉字: fontPt ≈ 汉字像素高 × PX_TO_IN × 72 / 0.92
西文: fontPt ≈ 大写字符高 × PX_TO_IN × 72 / 0.70
```

像素高用 `compare_text.py` 量：把源图**同时当源图和渲染图传两遍**，
`--band 名称:x1,y1,x2,y2` 输出的 source w,h 就是该文字带的像素包围盒，
取 h 减去上下留白估算字形高。

层级规范（与原图比例一致）：
- 主标题 > 面板标题 > 正文 > 注释/来源，同一层级字号必须统一；
- 常见落点：展板主标题 22~32pt，面板标题 14~18pt，正文 10~13pt，注释 8~10pt；
- 相对比例锁定后按换算式微调，不要四舍五入得太随意（12.5 就写 12.5）。

## 4. 字重与混排

- 加粗用 `bold:=True`；**书法类字体（行楷/舒体）没有粗体变体**，强加粗会
  假粗（描边增肥），这类字体标题宁可用字号/颜色分层。
- 中英混排：`FONT_NAME` 配西文（Arial 等），`FONT_NAME_CN` 配中文；
  数字归西文槽，原图数字若是无衬线而中文是宋体，就照此分离设置。
- 竖排、艺术拉伸（横粗竖细的伪粗体）超出引擎能力——降级为同族粗黑并
  在交付说明里注明。
