# 两轮评审标准（展板 / 海报 / 卡通示意图，交付前必过）

生成 `modPoster_Content*.bas` 并跑完 `build_poster.py` 后，**必须按顺序过两轮评审**，
任一轮不通过都要修复后重新生成，再从头评审。`references/review_examples/` 里有
`origin.png`（风格基准正样本）与 `failed.png`（失败案例渲染图），是本轮评审的
正/负样本：评审前先看一遍这对样本，把失败案例踩过的坑记在脑子里。

程序化工具链（都在 `scripts/`）：

- `lint_vba.py` —— 交付前的结构自检（常量 / `DrawAll` / 空实参 / kind / 颜色常量 / 编码）。
- `render_preview.py` —— 把 `.bas` 重放成 `preview_render.png`，并与源图并排拼成
  `preview_compare.png`，供两轮评审目测对照。
- `review_render.py` —— 对 `build_poster.py` 产出的 `poster.pptx` 做程序化几何体检。
- `measure_colors.py` —— 评审一取色（主色 / 区域底色 / 文字色 / 强调色，程序化）。
- `compare_text.py` —— 评审一字号校准（源图 vs 渲染图同带暗像素对比）。
- `font_check.py` —— 评审一字体可用性验证（中文字体必须已安装）。
- `icon_tool.py` —— 图标素材透明 / 分辨率校验（`check` 子命令）。

## 评审一：风格与源图一致性（看 `.bas` 调色板 / 字号 / 字体 + 预览渲染图）

**评审对象**：`modPoster_Content*.bas` 的调色板与字号常量、`render_preview.py`
产出的 `preview_compare.png`（上源图 / 下渲染）。
**评审方式**：多模态对照 + 程序化取色/字体互验。

### 1. 配色一致性（逐个调色板常量对照原图）

- [ ] 每个颜色常量都能在原图上指出来源区域；取色用 `measure_colors.py`
      程序化测（`--box 名称:x1,y1,x2,y2`），不许目测猜。
- [ ] **强调色饱和度不漂移**：原图的鲜蓝标题、橙黄强调、绿色亮点，渲染图里
      必须同样饱和。典型失败（见 failed.png）：标题条从鲜蓝褪成灰蓝，
      视觉上"褪色"。
- [ ] **面板衬底不过度稀释**：浅蓝/浅橙/浅绿面板底色深浅要和原图一致。
      典型失败：面板底色淡到近乎白色，三栏分区感消失。
- [ ] **背景深浅正确**：`AddBG` 的 `c1/c2` 取原图背景主色；渐变方向（上→下）
      与原图一致；盖板策略下不透明面板盖住烧死在原背景上的文字。
- [ ] 文字颜色与底色对比度足够：深底配白字、浅底配深字；标签文字不取描边灰。

### 2. 字体一致性

- [ ] **字体家族**与原图一致：黑体/无衬线 → `Microsoft YaHei`（西文）/ `微软雅黑`
      （中文 `FONT_NAME_CN`）；宋体/衬线 → `SimSun`/`宋体`；楷体 → `KaiTi`/`楷体`；
      圆体 → `YouYuan`/`幼圆`；行楷等书法体 → 对应已装字体。整图家族须与原图一致，
      且 `font_check.py` 全部 `[可用]`（中文用 `FONT_NAME_CN` 写，西文用 `FONT_NAME`）。
- [ ] **字号层级**保持原图比例：主标题 > 面板标题 > 正文 > 注释。用
      `compare_text.py` 按文字带暗像素宽/高反推：
      `python scripts/compare_text.py <源图> <preview_render.png>
      --band 名称:x1,y1,x2,y2 ...`（不传 `--band` 自动逐带扫描）。
      宽度比 >1.15x 视为渲染偏大、<0.85x 视为偏小；**禁止一律 12pt**。
      **中文源图加 `--cjk`**：单行中文文字带高度 ≈ 字号，按高度比反推
      比宽度比可靠（中文宽度受字数影响）。
- [ ] 粗体使用与原图一致：原图哪里加粗渲染图就哪里加粗（标题条、面板标题
      通常加粗，正文通常不加粗）。

### 3. 图标 / 卡通素材

- [ ] 图标 PNG 已用 `icon_tool.py check` 验证**透明**（无方块白底），且分辨率
      够（缩放后不糊）。搜不到合适素材时从原图抠（`icon_tool.py cut`）或引擎形状拼贴。
- [ ] 图标位置、大小贴合原图；图标区域若是照片/复杂纹理且抠图失败，已换成
      搜索素材或形状拼贴，**未硬抠**。
- [ ] **无占位框残留**：除非素材确实缺失并已向用户说明，渲染图里不应出现
      灰色虚线 `IMG 文件名` 占位框（评审二程序化会直接判 ERR）。

### 4. 数据图

- [ ] 选了"空着"→ 虚线占位框（`LINE_DASH` + 灰字），与原图留白一致。
- [ ] 选了"简单画一个"→ `AddBars` 原生柱状图，**类目名 / 数值**与内容一致，
      柱高比例合理，数值标签无溢出柱顶。

### 5. 整体风格

- [ ] 背景还原：纯色/渐变/装饰位置正确；盖板策略下原图烧死文字全部被盖住。
- [ ] 对齐与留白：面板顶边/中线对齐到网格；区块间距均匀，不挤成一片也不空旷。
- [ ] 卡通装饰（星星/爱心/云等）位置自然，**不遮挡**标题与正文。

**评审一不通过的处置**：修调色板常量 / 字号 / 字体 → 重跑
`render_preview.py` → 重新对照，直到通过才进 `build_poster.py`。

## 评审二：最终 PPT 渲染检查（看 `poster.pptx` 渲染图 + 程序化几何检查）

**评审对象**：`build_poster.py` 产出的 `poster.pptx`（有 PowerPoint 时导出幻灯片
PNG，无 PowerPoint 时用 `preview_compare.png` 回放图，二者语义等价），
外加 `scripts/review_render.py` 的程序化报告。

### 1. 文字是否溢出面板（文本溢出检查）

- [ ] **任何文字都不得溢出所属面板/节点框**：程序化按真实字体量宽
      `len(行) × pt × 系数`（CJK 感知）与框内宽比较，垂直方向按
      `行数 × pt × 1.25` 与框内高比较；超界即 FAIL。
      典型失败（见 failed.png）：面板正文贴穿面板底边。
- [ ] 字号与面板尺寸比例要和原图观感一致：字大而满不行（溢出/拥挤），
      小而空也不行（failed.png 里正文明显小于原图比例，整框发空）。
- [ ] 需要两行的文字必须显式写 `"A" & vbLf & "B"`；不允许依赖自动折行
      （自动折行断点不可控，垂直居中也会失效）。
- [ ] 文字在面板内水平+垂直居中（或按 `SetPara` 左对齐），不贴边、不压框线。

### 2. 图标 / 图片位置与清晰度

- [ ] 图标位置、大小贴合原图；无占位框残留（否则评审二 ERR）。
- [ ] 图标放大后不发糊（failed.png 列表框里的图标被拉成大虚框）；
      分辨率不足时 `icon_tool.py cut --scale` 或换素材。

### 3. 背景与面板还原

- [ ] 纯色/渐变方向正确；盖板策略下原图烧死文字全部被不透明面板盖住，无漏字。
- [ ] 面板位置、大小、留白与原图对应（允许 5% 内偏差）。

### 4. 卡通装饰与几何

- [ ] 卡通装饰（星星/爱心/云等）位置自然，不遮标题与正文（failed.png 里星星
      压在标题条上）。
- [ ] 所有形状都在幻灯片画面内，无出界。
- [ ] 带箭头的 `AddPath`（流程箭头）端点贴到目标形状边界，无悬空、不穿模。

**程序化检查**：`python scripts/review_render.py <输出目录>` 自动对
`poster.pptx` 做文本溢出估算 + 图标缺失/出界 + 装饰遮挡 + 出界检测，
输出 PASS / FAIL 清单。脚本报 FAIL 即评审二不通过。

**评审二不通过的处置**：修 `.bas`（坐标/字号/`vbLf` 换行/图标位置）→ 重跑
`build_poster.py` → 再跑 `review_render.py`。最多迭代 3 轮；仍不过则停下向
用户说明剩余问题。

## 失败案例速查表（review_examples/failed.png 对照 origin.png）

| # | 失败点 | 归属评审 | 修法 |
|---|--------|---------|------|
| 1 | 标题条鲜蓝褪成灰蓝 | 一·配色 | 程序化取标题条主色，禁止目测；`measure_colors.py` |
| 2 | 三块面板衬底色淡到近乎白色 | 一·配色 | 衬底色直接取原图面板区主色（median） |
| 3 | 面板正文贴穿面板底边 | 二·字体 | 缩字号或加大面板高度，文字必须居中 |
| 4 | 正文比原图比例明显偏小，框内大片空白 | 一/二·字体 | `compare_text.py` 反推字号，宁大勿小 |
| 5 | 电池图标变成灰色虚线 `IMG battery.png` 占位框 | 二·图标 | 确认 `ASSET_DIR` 绝对路径与文件名；放好素材后重跑 |
| 6 | 图标放大发糊成虚框 | 二·图标 | `icon_tool.py cut --scale` 或换更高清素材 |
| 7 | 五角星压在标题条上遮挡文字 | 二·装饰 | 挪装饰坐标，确保不盖文字/面板 |
| 8 | 柱状图类目/数值与内容不一致 | 一/二·数据图 | `AddBars` 的 cats/vals 按内容核对 |
| 9 | 形状/图标超出幻灯片边界 | 二·几何 | 重算坐标/缩放，确保在画面内 |
